# Nutridit · Contenido

Repositorio de trabajo para crear contenido de nutrición para **Nutridit**: publicaciones para redes sociales, artículos de blog y otros formatos.

## Estructura

- `kb/` — **Base de conocimiento (KB)**. Documentos de referencia que debe respetar todo el contenido:
  - `KB-01` Ficha de negocio, contacto y horarios
  - `KB-02` Servicios y precios
  - `KB-03` Paquetes de acompañamiento
  - `KB-04` FAQ maestro
  - `KB-05` Tono de voz y estilo
  - `KB-06` Calificación, encaje y derivación
  - `KB-07` Límites clínicos, RGPD y publicidad
  - `KB-08` Rutas de conversión: cita y paquete
  - `KB-09` Plataforma web: reserva y pago

## Uso

Antes de redactar cualquier pieza, consulta la KB, en especial el tono de voz (`KB-05`) y los límites clínicos y legales (`KB-07`).
